# @api21/admin

Admin dashboard application skeleton for the `api21` monorepo.

## Overview
This workspace is reserved for the upcoming admin dashboard. It interfaces with `@api21/api` management endpoints (health, queue metrics, active sessions) and shares types directly via `@api21/types`.

## Scripts
- `pnpm dev`: Run in watch mode.
- `pnpm build`: Build the TypeScript project.
